### Overview

This is an addon to the popular Farmer's Delight mod.
Slavic Delight adds many dishes and ingredients of Slavic cuisine to minecraft.

Special thanks to [vectorwing](https://github.com/vectorwing) for the [Farmers' Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight) source code!
